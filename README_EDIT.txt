UNDANGAN DIGITAL RADEN & SANTI — VERSI TERBARU

Alur baru:
1. Video opening Raden & Santi diputar otomatis satu kali.
2. Setelah video selesai, muncul gambar cover terbaru dengan tombol "Buka Undangan".
3. Tombol membuka isi undangan digital lengkap.

FILE PENTING:
- index.html  -> tampilan dan animasi/fitur website
- data.js     -> DATA undangan yang mudah diedit
- assets/opening-raden-santi.mp4 -> video opening terbaru
- assets/landing-raden-santi.png -> gambar setelah opening
- assets/foto-1.jpg s/d foto-10.jpg -> foto galeri/timeline
- assets/gamelan-raden-santi.mp3 -> musik instrumental bernuansa gamelan Jawa (original)

CARA EDIT DI GITHUB:
- Untuk teks, tanggal, rekening, lokasi, nomor WhatsApp, buka data.js lalu tekan ikon pensil/Edit.
- Untuk mengganti foto, upload foto baru ke folder assets dan ubah nama file di data.js atau index.html.
- Untuk mengganti video opening, upload MP4 baru ke folder assets lalu ubah nama source di index.html pada "opening-raden-santi.mp4".
- Untuk mengganti gambar setelah opening, upload gambar baru ke assets lalu ubah "landing-raden-santi.png" di index.html.

MUSIK:
- Musik bernuansa gamelan Jawa akan mulai otomatis setelah tombol "Buka Undangan" ditekan (sesuai aturan autoplay browser).
- Tombol ♫ di kanan bawah dapat digunakan untuk pause/play.
- Untuk mengganti musik, upload file MP3 ke folder assets lalu ubah music.file di data.js.

PESAN/UCAPAN:
Form "Kirim Pesan & Doa" akan membuka WhatsApp dengan nama dan pesan yang diisi tamu.
Jika ingin mengganti nomor WhatsApp penerima, ubah contact.whatsapp di data.js.

CATATAN GITHUB PAGES:
Pastikan file index.html berada di root repository dan Pages memakai branch main / folder root (/) setelah perubahan disimpan.
Setelah upload/commit, tunggu beberapa saat lalu refresh halaman dengan cache baru.
